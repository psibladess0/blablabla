# Пересечение

Сайт для сравнения музыкальных вкусов по Яндекс Музыке.

## Запуск у себя
    pip install -r requirements.txt
    python app.py          # http://localhost:8000

## Публикация (Render, Railway, VPS)
- Команда запуска: `gunicorn -w 1 --threads 8 -b 0.0.0.0:$PORT app:app`
- Нужен ровно один процесс (-w 1): комнаты хранятся в памяти.
- Сайт обязательно должен работать по HTTPS, потому что люди вводят токены.

## Как это устроено
- Токен используется один раз при добавлении и не сохраняется. В памяти остаются только названия.
- Комната живёт 24 часа, максимум 8 участников.
